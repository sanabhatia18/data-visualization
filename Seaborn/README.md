# Seaborn Practice

A structured collection of hands-on Python notebooks and exercises focused on **statistical data visualization, data exploration, and relationship analysis** using Seaborn.

## Topics Covered

* Lineplot — Visualizing trends over time
* Barplot — Comparing categorical data
* Countplot — Visualizing category counts
* Scatterplot — Exploring relationships between variables
* Regplot — Visualizing relationships with trend lines
* Histplot — Analyzing data distributions
* Pairplot — Exploring relationships across multiple variables
* Heatmap — Visualizing correlation matrices

## Technologies

* Python
* Seaborn
* Matplotlib
* Pandas
* NumPy
* Jupyter Notebook

## Objective

To develop a strong foundation in **statistical data visualization and exploratory data analysis** using Seaborn as part of my Data Science and Machine Learning learning journey.
