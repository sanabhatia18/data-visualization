# Matplotlib Practice

A structured collection of hands-on Matplotlib notebooks and exercises covering fundamental data visualization techniques, plot customization, and statistical visualizations in Python.

##  Topics Covered

### Matplotlib Fundamentals
- Importing `matplotlib.pyplot`
- Preparing and working with data using Python lists
- Checking data length with `len()`
- Displaying plots with `plt.show()`

### Line Charts
- Creating line charts with `plt.plot()`
- Customizing line styles
  - Solid
  - Dashed
  - Dotted
- Changing line colors
- Adding plot titles
- Adding X-axis and Y-axis labels
- Adding legends with `plt.legend()`
- Changing figure dimensions with `figsize`

### Area Visualization
- Filling areas under line charts with `plt.fill_between()`
- Customizing plot background color

### Bar Charts
- Creating bar charts with `plt.bar()`
- Applying different colors to individual bars
- Adding text labels and annotations with `plt.text()`

### Pie Charts
- Creating pie charts with `plt.pie()`
- Adding labels to pie-chart sections
- Displaying percentages with `autopct`
- Rounding percentage values

### Multiple Plots
- Creating multiple plots using `plt.subplots()`
- Arranging plots in a 2×2 grid
- Combining line, bar, and pie charts in subplots

### Histograms & Random Data
- Generating random data using NumPy
- Creating histograms with `plt.hist()`
- Setting the number of histogram bins
- Adjusting histogram bar width using `rwidth`

## 🛠️ Technologies & Tools

- **Python**
- **Matplotlib**
- **NumPy**
- **Jupyter Notebook**

##  Objective

The objective of this practice is to develop a strong foundation in **data visualization using Matplotlib** and understand how to create, customize, and interpret different types of visualizations.
