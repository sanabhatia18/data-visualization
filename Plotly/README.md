# Plotly Practice

A structured collection of hands-on Python notebooks and exercises focused on **interactive data visualization and exploratory data analysis** using Plotly and Plotly Express.

## Topics Covered

* Plotly installation and setup
* Plotly Express
* Built-in datasets
* Pandas grouping and aggregation
* Line charts
* Bar charts
* Grouped bar charts
* Scatter plots
* Categorical coloring
* OLS trendlines
* Logarithmic axes
* Animated charts
* Hover labels
* Sunburst charts

## Technologies

* Python
* Plotly
* Plotly Express
* Pandas
* NumPy
* Jupyter Notebook

## Objective

To build a strong foundation in **interactive data visualization and exploratory data analysis** using Plotly as part of my Data Science and Machine Learning learning journey.
